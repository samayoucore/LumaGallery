# Luma Gallery

**Luma Gallery** is a WordPress-based online gallery pet-project created as a portfolio case for web development, custom WordPress architecture, frontend UI work, and AI-assisted development workflow.

The project combines an editorial gallery interface, custom post types for artworks, artists and exhibitions, favorites, experimental AI-inspired UI features, and a demo commerce flow.

> Status: Work in Progress  
> This project is actively being developed and improved step by step.

---

## Project Goals

The main goal of Luma Gallery is to demonstrate practical web development skills through a realistic WordPress project:

- custom WordPress theme development;
- custom plugin architecture;
- working with CPTs, taxonomies and metaboxes;
- frontend UI/UX implementation without relying on ready-made themes;
- SCSS/JS asset pipeline with Gulp;
- interactive frontend features;
- AI-assisted development workflow;
- portfolio-ready project structure.

This repository is not just a visual landing page. It is designed as a more complete WordPress-based product concept.

---

## Main Features

### Current / Implemented

- Custom WordPress theme: `luma-gallery`
- Custom WordPress plugin: `luma-core`
- Custom Post Types:
  - Artworks
  - Artists
  - Exhibitions
  - Journal / content-related entities
- Custom taxonomies and metaboxes
- Demo data logic
- Favorites system
- WooCommerce helper logic
- Fake payment gateway for demo commerce flow
- Shortcodes
- AI-inspired frontend modules:
  - AI Assistant
  - AI Curator
  - View in Room
  - Gallery Walk
- Interactive UI modules:
  - cursor light effect
  - modals
  - filters
  - favorites
- Gulp 4 build setup
- SCSS architecture with separated base, components, sections and pages
- JavaScript modules compiled into a single minified file
- Editorial brutalist visual direction
- Hero section with sculpture image and parallax-like visual feel
